# Simulador de Investimentos em Fundos Imobiliários (Excel)

## 📌 Descrição do Projeto
Este projeto consiste na criação de uma ferramenta simples desenvolvida em **Microsoft Excel** para simular investimentos em **Fundos de Investimento Imobiliário (FIIs)**.  
A planilha permite ao usuário visualizar de forma clara o valor investido, o patrimônio acumulado e os dividendos mensais, auxiliando na compreensão do impacto dos aportes ao longo do tempo.

O modelo é voltado principalmente para **investidores iniciantes**, oferecendo uma solução prática, acessível e fácil de utilizar, podendo servir como base para futuras expansões e personalizações.

## 🎯 Objetivo
- Simular investimentos em fundos imobiliários  
- Calcular o valor total investido  
- Estimar o patrimônio acumulado  
- Calcular os dividendos mensais esperados  

## 🛠️ Funcionalidades
- Inserção de aportes mensais  
- Cálculo automático do total investido  
- Estimativa de rendimento mensal (dividendos)  
- Visualização simples e intuitiva dos resultados  

## 📊 Ferramentas Utilizadas
- Microsoft Excel  

## 👥 Público-Alvo
- Investidores iniciantes  
- Estudantes de finanças  
- Pessoas interessadas em planejamento financeiro pessoal  

## 🚀 Possíveis Evoluções
- Inclusão de gráficos de evolução patrimonial  
- Simulação de reinvestimento de dividendos  
- Comparação entre diferentes FIIs  
- Ajuste automático por inflação  

## 📄 Observações
Esta planilha tem caráter **educacional e simulativo**, não substituindo a orientação de um profissional financeiro.
